LOF：不看你离人多远，只看你和邻居一样密吗

KNN 用绝对距离，于是把整个稀疏簇判成异常。LOF 换掉参照系：把「我离邻居多远」改成「我的密度和邻居的密度差多少」——分数从绝对量变成相对量。这一页把这个相对量一层层拆开。

Ⅱ 族 邻近度与局部几何数据 C4 · 密度反差 + 边缘孤点 PyOD 3.6.7 实测分数接 KNN 课件的破口
01

破口：KNN 的绝对距离错在哪

主线定位

主线定位：正常 = 密度与邻居相当；分数 = 局部密度比；本节破口 = 邻域仍是球状 → 2.3 由 COF 补。

回头看 KNN 课件的双密度簇（数据 C2）：密簇 180 点 σ=0.35、稀疏簇 10 点 σ=1.5，两簇全是正常点。KNN k=10 给 3 个稀疏簇普通点打出 3.666 / 3.463 / 4.345，全线越过 P95=1.191 —— 100% 误报。

KNN 的推理是「离邻居远 ⇒ 异常」，而稀疏簇里所有正常点都离邻居远。问题不在阈值、不在 k，在于它拿同一个绝对尺度去衡量密度天差地别的两处地方。

同一份 C2 数据、同一个 k=5，只把模型从 KNN 换成 LOF（PyOD 3.6.7 实测）：

模型正常点 P953 个考察点分数高于 P95
KNN k=51.1163.021 / 2.290 / 4.1143 / 3
LOF k=51.6621.281 / 1.134 / 2.9931 / 3
✅ 前两个稀疏簇普通点从 3.02 / 2.29 回落到 1.28 / 1.13（≈ 1，即「和邻居一样密」）；只有 P3 仍偏孤立被标出。LOF 没调松阈值，它换了参照系：分母不再是「全空间的距离」，而是「我邻居的密度」。
📌 与 Ⅰ 族再对一次：Ⅰ 族问「你在分布里概率多大」（全局、绝对），KNN 问「你旁边有没有人」（局部、绝对），LOF 问「你和邻居一样挤吗」（局部、相对）。两个字的差别，就是这一节能不能同时容纳两种密度的簇。
02

四步原理：从距离到密度比

Breunig et al., 2000

LOF 一共四层，每一层都只在上一步的结果上做一次「局部化」。

① k-距离dk(x) = x 到第 k 近邻的距离 每个点自己的「邻域尺度」
② 可达距离reachk(x ← o) = max{ dk(o), d(x, o) } 用邻居 o 的尺度给距离设下限
③ 局部可达密度lrdk(x) = 1 / [ (1/k) · Σo∈Nk(x) reachk(x ← o) ] 平均可达距离的倒数
④ LOF 分数LOFk(x) = [ (1/k) · Σo∈Nk(x) lrdk(o) ] / lrdk(x) 邻居平均密度 ÷ 我的密度
  • ① k-距离就是 KNN 课件里的 dk(x)，但这里它不再是分数，而是尺度：描述 o 周围「一步」大概有多长。
  • ② 可达距离关键减震器。x 与 o 挨得特别近时，d(x,o) 的微小抖动会让密度估计剧烈跳变；max 用 o 自己的 dk(o) 兜底，把小于邻域尺度的距离一律「抹平」。这是 LOF 比朴素 kNN 距离稳健的原因。
  • ③ lrd把 k 个邻居的可达距离取平均再取倒数：邻居越近，密度越大。注意这是带邻居尺度的密度，不是简单的 1/距离。
  • ④ LOF把「邻居们的平均 lrd」除以「我的 lrd」——一个比值。两边同时缩小 10 倍（整个簇稀疏 10 倍），比值纹丝不动。这就是「局部」二字的全部数学含量。

图 1 · 可达距离：橙色虚线圈是邻居 o 的邻域尺度 dₖ(o)，短于它的距离一律被抬到这个下限

📌 实现细节（复现分数时容易踩坑）：PyOD 的 LOF 是 scikit-learn LocalOutlierFactor 的封装，默认 novelty=True（所以能给新点打分）。sklearn 原始输出是负的离群因子（越小越异常），PyOD 统一反转符号为「越大越异常」——与全库其它算法口径一致。
03

怎么读 LOF 分数：≈ 1 才是正常

相对量，无单位

LOF 是一个比值：分母是我的密度，分子是邻居的平均密度。

图 2 · 三种点的密度对比：A 与 B 的绝对密度差 10 倍，但 LOF 都 ≈ 1；只有 C 与邻居不匹配

LOF 值含义典型场景
≈ 1我和邻居一样密 → 正常（哪怕整个簇很稀疏）图 2 的 A、B；KNN 会把 B 误报
≫ 1我明显比邻居稀 → 异常密簇边缘孤点、小簇外的点
< 1我比邻居还密（处在更密区域内部）通常仍判正常；极端值提示 k 或度量选得不合适
💡 「相对量、无单位」带来两个直接好处：① 不同密度的簇可以放在同一条判定线下比较；② 分数不随整体缩放改变。但也别把它当概率——LOF 不做校准，没有「LOF=1.5 就是 15% 异常」这种解释。

专属数据与交互实验

数据 C4课件 §2.2

题目：更极端的密度反差，再放一个紧贴密簇边缘的孤点。

左簇 200 点挤在 σ=0.28，右簇 100 点摊在 σ=1.6，两簇全是正常点；3 个考察点里 P1 / P2 是稀疏簇里的普通点，P3 是紧贴密簇边缘的孤点。只有同时存在「整体稀疏但局部一致」和「局部明显更稀」两类点，才考得出相对量的价值。

考察点LOF 分数怎么读

P2 (2.4, 1.2) 稀疏簇内0.979≈ 1 → 正常，密度和邻居相当

📌 前两个稀疏簇普通点稳稳落在 ≈ 1（0.97 / 0.98），KNN 那种「整个簇被误报」的问题消失了；P3 的 1.459 是它们的 1.5 倍，明确表现出「局部比邻居稀」。在 k≤19 时 P3 越过 P95，k=20 时紧贴判定线下沿（1.459 vs 1.477）——看相对关系比死守阈值更可靠。

05

破口与边界：LOF 也不是万能的

通向 2.3 COF

LOF 补上了「密度不均」，但它仍然用球形邻域找 k 个最近的点。

  • 球状邻域假设当「簇」不是一团、而是一条弯曲的带子时，欧氏最近邻会跨过带子的弯折去抓另一侧的点，局部密度被算错 → 2.3 COF 改用链式连通距离补这个破口。
  • k 必须小于最小簇规模切到上方交互的 C2 数据看：稀疏簇只有 10 个点，k=3 时 LOF 0/3 误报（修好了 KNN 的问题）；k≥10 时每个点的邻居必然跨到密簇去，3/3 全部误报，甚至比 KNN 更糟。k 是「邻域尺度」，不是越大越稳。
  • O(n²d) 与维度灾难近邻搜索 + 每个点的 lrd 都要算，数据量大时吃力；维度一高，距离趋同，k 近邻结构失去意义 → 跳 Ⅲ 族 IForest / LODA，或先降维。
  • 边缘与小簇敏感紧贴大簇的孤点、规模很小的簇会被显著抬高；LOF 分数无上界，阈值请用 P95 或业务可接受的告警量来切。
⚠️ 和 Ⅱ 族所有成员一样，必须先标准化再算距离，否则量纲大的那一维会独占「近邻」的定义，结论全错。

参数速查与主线衔接

PyOD 3.6.7
参数默认说明与建议
n_neighbors20邻域规模。要足够大以压住噪声，但必须小于数据里最小簇的点数；本页 C4 实验用 20，C2 上只有 k=3~5 才成立。
algorithm'auto'近邻搜索结构：ball_tree / kd_tree / brute；由 sklearn 的 LocalOutlierFactor 执行。
metric / p'minkowski' / 2距离度量；p=2 即欧氏距离。换度量要连「邻域是球形」这个假设一起重新想。
noveltyTruePyOD 默认为 True，因此 decision_function 可以给训练时没见过的新点打分。
contamination0.1只影响 predict 的切分阈值，不改变分数排序。
n_jobs1近邻搜索并行度；大数据量可开。

Ⅱ 族：同一个内核（近邻）+ 五次换参照系

算法参照系换成什么补掉什么破口
KNN §2.1到第 k 近邻的绝对距离—（起点）
LOF（本页）与 k 个邻居比相对密度双密度簇误报
COF §2.3流形上的连通路径距离簇是弯曲带子时球形邻域失真
CBLOF §2.4所属簇的规模与到簇的距离全局距离看不见簇结构
SOD §2.5局部低方差子空间噪声维淹没近邻结构
✅ 何时用 LOF：中小规模、低中维、各区域密度不一致的表格数据，且关心「局部孤点」而非「全局离群」。它是 KNN 之后最该试的第二个基线。

复现

与 notebook 一致

本页所有图形与分数由 1.PYOD.原理主线版.ipynb §2.2 的专属数据算出（确定性构造、无随机数）。复现只需两行：

# --- LOF · 专属数据实验（极端密度反差）---
from pyod.models.lof import LOF                                 # Ⅱ 族：局部离群因子

m = LOF(n_neighbors=20)                                         # 20 近邻，看相对密度
diagnose(m, 'LOF', 'LOF', scale=True, plot=True)                # 标准化 + 打分 + 画图

判分规则：不比 AUC，只看考察点有没有排到正常点分数 P95 之上。PyOD 3.6.7 实测：P95=1.477，P1=0.972 / P2=0.979 / P3=1.459；两个稀疏簇普通点回落到 ≈1，边缘孤点约为它们的 1.5 倍。

💡 版本提示：不同 PyOD / sklearn 版本下，P3 是否恰好越过 P95 可能有细微差别（k=20 时它离判定线很近）。判断标准请抓相对关系：P1、P2 ≈ 1，P3 明显更高；想让 P3 稳定越线，把 k 调到 10~19 再看。
