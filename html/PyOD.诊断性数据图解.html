先拿地图：哪份数据打哪条假设

读法：先只看图，猜一猜这个点该不该判异常，再看下面对应的算法会怎么答。

族算法诊断数据要暴露的破口
ⅠECOD / HBOSC1 相关带 + 组合异常边际独立 → 漏掉组合异常
ⅡKNN / LOF / CBLOFC2 紧密簇 + 稀疏簇绝对距离误判稀疏簇
ⅡCOFC3 弯曲链 + 孤点直线距离误判细长队伍
ⅡSODC4 子空间 + 噪声维全局距离被无关维淹没
ⅢIForestC5 远处小簇密度法漏掉「抱团」的少数派
ⅢLODAC6 投影可分单一投影方向会失手
ⅣOCSVMC7 环形 + 中心空洞边际分布把圆心当最正常
ⅣAutoEncoderC8 一维流形污染训练集 → 异常被学会
三类数据分工：擂台 A（单高斯）用来公平横评 AUC；擂台 B（多密度簇）用来暴露 Ⅱ 族前几个的假设；这里的擂台 C 只用来说明原理，不比 AUC。
与课件是同一批点：本页 8 张图的每个蓝点／红点，都由课件 实验准备 的 make_diagnostic_cases() 生成；在课件里跑 diagnose(..., plot=True) 会画出同一形状并叠加决策分数。构造不用随机数，因此不依赖 numpy 或随机种子实现。
01

ECOD

Ⅰ 族 数据 C1课件 1.1

先别急着回答：一个点，两维都在正常范围里，它是异常吗？

两侧直方图就是 ECOD 看到的全部信息：红点落在高柱里，所以它不觉得奇怪。

  • 数据怎么造正常点沿 y ≈ x 排成一条带；红点取 (2, −2) 这类位置 —— x 和 y 单独看都不极端。
  • 专门打哪条假设ECOD 逐维算经验累积分布的尾部概率，再相加；它默认各维独立，看不见维度之间的关系。
  • 预期看到的红点的左右尾概率都不小 → 分数接近正常点；擂台 A 的单高斯数据永远暴露不了这一点。
  • 谁不会看走眼Ⅱ 族的 KNN / LOF 看的是点与点的几何关系，红点明显在带子外面。
结论 · Ⅰ 族的破口不是「算不准」，而是「根本没看」：特征之间的相关结构在投影到单维时被丢掉了。
02

HBOS

Ⅰ 族 数据 C1课件 1.2

先别急着回答：把直方图桶数调到 50，能把这个红点抓出来吗？

同一批点：HBOS 用每维直方图的高桶判正常，红点两维都进了高桶。

  • 数据怎么造沿用 C1 的相关带与组合异常点。
  • 专门打哪条假设HBOS 打分是各维 −log P(xⱼ) 之和，等于假设联合密度 = 各边缘密度相乘。
  • 预期看到的调大 n_bins 只会让桶更细，红点仍落在 x、y 各自的高密度区 —— 这是假设问题，不是参数问题。
  • 教学价值这一张图同时解释了为什么 0.3 把 HBOS 从官方的 Proximity-Based 挪到 Ⅰ 族：它按原理是逐维密度。
结论 · 换参数救不了被破坏的假设。要抓组合异常，只能换成会看维度关系的模型。
03

KNN

Ⅱ 族 数据 C2课件 2.1 / 2.2

先别急着回答：右簇里随便挑一个点，它的第 k 近邻距离，会不会比左簇的异常点还大？

两个簇里的点全是正常点，但右簇的邻居天然更远。

  • 数据怎么造左簇 180 点、标准差 0.35；右簇 120 点、标准差 1.35 —— 密度和样本数都不同。
  • 专门打哪条假设KNN 的分数是绝对距离，隐含「全空间密度大致均匀」。
  • 预期看到的稀疏簇的正常点被大面积推高分数；AUC 单独看没意义，要看分数在两簇之间的分布。
  • 对照这正是 2.2 擂台 B 存在的原因 —— 单高斯数据里两个簇不存在，缺陷永远看不出来。
结论 · 绝对距离不区分「这里本来就稀疏」和「这个点格外孤立」。
04

LOF

Ⅱ 族 数据 C2课件 2.3

先别急着回答：不换数据，只换参照系，右簇还能被救回来吗？

同一批点，LOF 把每个点跟它自己的邻居比，而不是跟全局比。

  • 数据怎么造沿用 C2；特意放的两个点都在两簇之外，用来对照「相对密度」的读图效果。
  • 专门打哪条假设LOF 分数 = 邻居的平均局部可达密度 ÷ 自己的，是相对量。
  • 预期看到的稀疏簇的普通点在图上不再被高分区覆盖（与 KNN 那张图对照），特意放在簇外的点仍被抓到。
  • 读图要点高分区贴着每个簇的外缘各自成形，而不是像 KNN 那样圈出一个大圆。
结论 · 「局部」二字的分量：分数是比值，所以能同时容纳紧密簇与稀疏簇。
05

COF

Ⅱ 族 数据 C3课件 2.4 ｜ 本页数据直接来自附件

先别急着回答：中间那条稀疏的队伍，到底算不算异常？先别急着回答。

照抄《COF图解.html》的 26 个手工点：密集团、细长队伍、孤零零的红点。

  • 数据怎么造密集团 15 点 + 弯曲细长队伍 10 点 + 孤点 1 个；队伍中段刻意留稀。
  • 专门打哪条假设LOF 用欧氏直线距离定邻域，隐含「正常区域是各向同性的团」；沿带子走很远其实仍正常。
  • 预期看到的LOF 会把队伍中段的点推高；COF 用 SBN 链式距离「顺着队伍走」，每一步都短，于是判正常。
  • 对照孤点两种方法都会抓 —— 有分歧的只有细长队伍，这说明分歧来自距离定义，不是阈值。
结论 · LOF 量「直线距离」，COF 量「顺着数据形状走的距离」。代价是 COF 要对每个点维护最短路径。
06

CBLOF

Ⅱ 族 数据 C2课件 2.5

先别急着回答：右簇比左簇稀疏，点也更少。它算正常模式，还是异常簇？

先把点划成簇，再按簇的大小决定「到谁的中心」算距离。

  • 数据怎么造沿用 C2：左簇 180 点紧密、右簇 120 点稀疏，大小簇确实不等。
  • 专门打哪条假设CBLOF 用 KMeans 把逐点近邻换成簇，大簇代表主要正常模式，小簇按到最近大簇中心的距离打分。
  • 预期看到的大小簇划分由 alpha 控制；改一次 alpha，看小簇的分数整体跳变 —— 这是它最敏感的地方。
  • 教学价值它把 O(n²) 降到 O(nk)，也说明「邻居」的参照系可以一路换到簇级别。
结论 · Ⅱ 族五次换参照系：KNN 绝对距离 → LOF 相对密度 → COF 形状 → CBLOF 簇 → SOD 子空间。
07

SOD

Ⅱ 族 数据 C4课件 2.6

先别急着回答：如果再塞 8 维无关噪声，这个偏离带的点还找得到吗？

只画前两维；另外 8 维噪声没画出来，却足以淹没全局距离。

  • 数据怎么造前两维强相关成带，另 8 维是方差更大的纯噪声；异常点只在垂直带的方向偏离。
  • 专门打哪条假设全局欧氏距离在每个维度上平摊，噪声维度贡献大却不含信息。
  • 预期看到的全局 LOF 的分数被噪声抹平；SOD 在参考集里挑低方差子空间，重新把红点挑出来。
  • 为什么课件原来讲不清原代码用 2D 单高斯，自己都注明「仅作 API 演示」—— 二维里根本没有子空间可选。
结论 · SOD 的核心不是新分数，是「在哪个空间里找邻居」。
08

IForest

Ⅲ 族 数据 C5课件 3.1

先别急着回答：这一小撮点彼此挨得很近，算「孤立」吗？

黄色小簇内部密度不低，但它整块远离大团。

  • 数据怎么造大团 220 点 + 远处 7 点的小簇，小簇内部标准差只有 0.16。
  • 专门打哪条假设密度类方法看「周围有没有人」；小簇内部有人，LOF 容易漏。
  • 预期看到的随机选一个特征切一刀，几次就能把整块小簇单独切出来 → 路径短 → 高分。
  • 对照这解释了为什么 Ⅲ 族不定义「正常」也能工作：它只问「好不好隔离」。
结论 · IForest 抓的是「稀少且与主体可分」，不是「孤独」。
09

LODA

Ⅲ 族 数据 C6课件 3.2

先别急着回答：随手指一个投影方向，这次会不会白指？

同一个红点，投影到 x 轴混进人群，投影到 45° 方向就露出来。

  • 数据怎么造正常点云各向同性；异常点取 (0.3, 2.6) —— x 投影只有 0.3，正好混进人群，只有换投影方向才看得见。
  • 专门打哪条假设LODA 生成很多随机投影 w，每个投影建一维直方图，再把 −log P 平均。
  • 预期看到的多数方向分不开，但总有一部分方向能分开；集成后信号仍高于正常点。
  • 教学价值它一棵树都没有 —— 是 Ⅰ 族直方图 + Ⅲ 族随机集成的桥梁。
结论 · 随机化的价值：不赌某一个方向对，而是让足够多的方向一起投票。

OCSVM

Ⅳ 族 数据 C7课件 4.1

先别急着回答：圆心这个点，两个坐标都是 0，最「平均」了。它异常吗？

正常点围成一个环，中心是空的 —— 可那里恰恰是边际分布的中心。

  • 数据怎么造正常点均匀落在半径 2.6 的圆环上；异常点放在圆心和环外。
  • 专门打哪条假设Ⅰ 族看边际，圆心在两维的中心 → 最低分；线性重构也会把均值附近当正常。
  • 预期看到的RBF 核学出闭合的非凸轮廓，中心空洞落在边界外 → 高分。
  • 读图要点和 Ⅰ 族的矩形网格、Ⅱ 族的贴簇曲线对比，这是第三种完全不同的「正常」形状。
结论 · Ⅳ 族不手工定义偏离：模型自己学出正常区域的形状。代价是对 ν、γ 极敏感。

AutoEncoder

Ⅳ 族 数据 C8课件 4.2

先别急着回答：一个点离曲线只有半格，网络为什么还原不了它？

二维数据其实躺在一维曲线上：AE 的瓶颈只要记住曲线参数就够了。

  • 数据怎么造正常点沿 y = sin(x) 加小噪声；异常点在曲线外的几个位置。
  • 专门打哪条假设正常模式存在低维共性，瓶颈层被迫只保留沿曲线的 1 个自由度。
  • 预期看到的曲线上的点重构误差小；离线点的误差 ≈ 到曲线的距离。
  • 最隐蔽的失效若训练集里混进同分布的一小撮异常，网络会把它们也学会，误差反而变小。
结论 · 重构误差不是「罕见程度」，是「模型学没学会」—— 污染训练集的后果由原理直接推出。
✓

数据可复现性

  • 来源弯曲链的 26 个点取自链式流形经典例题；其余形状由下面的确定性公式算出，不用随机数发生器。
  • 本页数据来源下面这段函数生成本页的 8 种基础形状；课件另有一套按算法专属的 11 组数据，两边不再一一对应。
  • 怎么对答案不要只看 AUC。把特意放进去的那几个红点单独取出来，打印它们的分数与全体分位数，看「该高的有没有高」。
  • 为什么不用 AUC诊断数据里异常点常常只有 1~4 个，AUC 方差极大；它的用途是看图讲原理，不是排行榜。
def make_diagnostic_cases():
    """本页的 8 种基础形状：全部确定性构造，不调用任何随机数发生器。

    本页 SVG 由这段函数在构建时生成，不依赖 numpy 或随机种子的实现。
    抖动用整数哈希 + Box-Muller 生成，并截断到 ±2.8 个标准差，
    保证形状干净、SVG 坐标不越界。
    """
    import math

    def u(i, salt):
        t = math.sin((i + 1) * 12.9898 + salt * 78.233) * 43758.5453
        return t - math.floor(t)

    def g(i, salt):
        z = (math.sqrt(-2.0 * math.log(max(u(i, salt), 1e-6)))
             * math.cos(2.0 * math.pi * u(i, salt + 37.0)))
        return max(-2.8, min(2.8, z))

    C = {}

    # C1 相关带 + 组合异常：两维边际都正常，组合破坏 x ≈ y
    C['C1'] = dict(
        X=[[g(i, 1), g(i, 1) + .13 * g(i, 2)] for i in range(220)],
        A=[[2., -2.], [-2., 2.], [1.7, -1.6], [-1.8, 1.8]])

    # C2 紧密簇 + 稀疏簇：密度差一个数量级，且左 180 / 右 120 点不等
    tight = [[-2.2 + .35 * g(i, 3), .35 * g(i, 4)] for i in range(180)]
    loose = [[2.4 + 1.35 * g(i, 5), 1.35 * g(i, 6)] for i in range(120)]
    C['C2'] = dict(X=tight + loose, A=[[.1, 3.9], [6.4, -3.4]])

    # C3 弯曲链：26 个手工点取自链式流形经典例题
    cluster = [
        [1.0, 1.2], [1.5, .9], [2.1, 1.1], [2.6, .9], [1.2, 1.9], [1.8, 2.0], [2.4, 1.8], [2.9, 1.6],
        [1.0, 2.7], [1.7, 2.8], [2.4, 2.7], [3.1, 2.5], [1.6, 3.5], [2.4, 3.6], [3.0, 3.3]]
    chain = [
        [4.6, 3.6], [5.8, 3.9], [7.0, 4.5], [8.1, 5.2], [9.1, 6.1],
        [9.9, 7.1], [10.5, 8.2], [10.9, 9.4], [11.1, 10.7], [11.0, 12.0]]
    C['C3'] = dict(X=cluster + chain, cluster=cluster, chain=chain, A=[[.5, -3.5]])

    # C4 子空间：前两维强相关，另 8 维是方差更大的噪声
    C['C4'] = dict(
        X=[[g(i, 7), g(i, 7) + .12 * g(i, 8)] +
           [2.0 * g(i, 9 + j) for j in range(8)] for i in range(220)],
        A=[[0, 2.4] + [0] * 8])

    # C5 远处小簇：内部密度不低，但整体孤立（小簇就是要检出的点）
    big = [[.55 * g(i, 20), .55 * g(i, 21)] for i in range(220)]
    small = [[3.4 + .16 * g(i, 22), 3.0 + .16 * g(i, 23)] for i in range(7)]
    C['C5'] = dict(X=big, A=small, S=small)

    # C6 投影可分：异常点 x 投影落在正常范围内，只有换方向才看得见
    X6 = []
    for i in range(220):
        a, r = 2 * math.pi * u(i, 30), math.sqrt(u(i, 31)) * 1.1
        X6.append([r * math.cos(a), r * math.sin(a)])
    C['C6'] = dict(X=X6, A=[[0.3, 2.6]])

    # C7 环形：中心是空的
    X7 = []
    for i in range(240):
        th, R = 2 * math.pi * u(i, 32), 2.6 + .10 * g(i, 33)
        X7.append([R * math.cos(th), R * math.sin(th)])
    C['C7'] = dict(X=X7, A=[[0., 0.], [4.2, 0.]])

    # C8 一维流形 y = sin(x)
    X8 = []
    for i in range(220):
        t = -3.2 + 6.4 * u(i, 34)
        X8.append([t, math.sin(t) + .07 * g(i, 35)])
    C['C8'] = dict(X=X8, A=[[0, 1.9], [1.6, -1.4], [-2.2, 1.6]])
    return C
三句话带走：① 例子是为原理服务的，数据形状要能把假设的破口逼出来。② 同一份数据换算法看，比同一算法换数据看更能说明差别。③ 讲不清原理时，先问「哪个点会让它看走眼」。
